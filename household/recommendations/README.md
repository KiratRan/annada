# Recipe Recommendations

This directory contains generated recipe and meal suggestions.

Location:

$HOUSEHOLD_ROOT/recommendations


The household-wide instructions are:

$HOUSEHOLD_ROOT/ASSISTANT.md


---

# Purpose

Recommendation artifacts contain suggested meals generated from household data.

They are used for human review before creating meal plans.

Recommendations are not:

- approved meal plans
- grocery lists
- inventory records
- recipe library entries


---

# Ownership

Recommendations are generated by:

recipe-recommendation-agent


The recommendation agent may analyze:

- recipe library
- pantry inventory
- grocery promotions
- household preferences
- budget constraints
- preparation time


The recommendation agent must not:

- create meal plans
- modify recipes
- create grocery lists
- synchronize external systems


---

Recommendation artifacts are intermediate decision records.

They are not authoritative household records.

Authority:

Recipes:
recipe-library-manager

Recommendations:
recipe-recommendation-agent

Meal plans:
household-meal-planner

Grocery lists:
grocery-list-generator

household consumer (grocery list)

# Recommendation Schema

Example:


version: 1

status:
    state: pending

metadata:

  generated_at: 2026-09-07T10:00:00
  
  generated_by:
    skill: recipe-recommendation-agent

  planning_period:

    start: 2026-09-07

    end: 2026-09-13


  household_size: 4


recommendations:


  - recipe:

      id: chicken-tikka-masala


    score:

      overall: high
      factors:
        recipe_match: high
        pantry_alignment: medium
        budget_alignment: high
        preparation_fit: high
        variety: medium


    reasoning:

      - Existing household recipe

      - Uses discounted chicken

      - Fits preparation time target

    tradeoffs:

      - Requires fresh herbs not currently in pantry
      - Requires one additional grocery item


    considerations:

      preparation_time:

        suitable: true


      pantry_usage:

        items_used:

          - rice

          - spices


    approval:

      status: pending


Allowed:
  - approved
  - pending
  - rejected
  - expired

# Recipe References

Recipes are referenced by ID only.


Example:


recipe:

  id: chicken-tikka-masala


The ID must exist in:


$HOUSEHOLD_ROOT/recipes/index.yaml



Do not embed:

- recipe instructions
- full recipe ingredients
- complete recipe metadata

May include:

- recipe source type
- recipe path
- discovery source reference

Example:

  recipe:

    id: chicken-tikka-masala

    source:

      type: household_recipe

      path: $HOUSEHOLD_ROOT/recipes/chicken-tikka-masala.md

---

# Reasoning

Recommendations must explain why they were suggested.


Possible factors:


- existing household recipe
- pantry availability
- grocery promotion
- ingredient reuse
- preparation time
- household preference
- budget suitability


Reasoning must distinguish:


Verified:

Information found in household files or sources.


Suggested:

Agent-generated recommendation.


Unavailable:

Information that could not be retrieved.



---

# Deal Influence

If grocery promotions influence a recommendation:


Example:


reasoning:

  - Chicken is currently discounted at configured store


The recommendation must not:


- modify the recipe
- claim savings without a source
- include prices without verified data



---

# Pantry Influence

If pantry items influence a recommendation:


Example:


pantry_usage:

  items_used:

    - canned tomatoes

    - pasta



Do not assume pantry availability.

Only use recorded pantry data.



---

# Approval States

Allowed values:


pending

approved

rejected

expired



Workflow:


pending

|

v

human review

|

+-- approved

|

+-- rejected



Only approved recommendations may become meal plans.



---

# Validation Rules


Before saving:


Verify:


- recipe IDs exist
- reasoning is included
- sources are preserved
- unavailable information is identified
- approval state is valid



Do not:


- create recipes
- create meal plans
- create grocery lists
- synchronize external systems



---

# Meal Planner Handoff

Approved recommendations passed to:

household-meal-planner

contain:

- recipe IDs
- ranking information
- reasoning
- confidence
- constraints considered

The meal planner decides:

- calendar placement
- meal ordering
- servings
- leftover scheduling

The recommendation agent must not decide the final schedule.
